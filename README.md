# scRNA-seq-Analysis-for-RAS-inhibition-in-PDAC-Project

Single-cell analysis on the following models:
1) Degron-regulated KRASG12D-dependent transplantation model
2) KrasG12V-driven PDAC mouse model treated with the RAS(ON) multi-selective inhibitor RMC-7977

This repository contains processed single-cell RNA sequencing (scRNA-seq) datasets and code used to explore gene expression in mouse models pancreatic ductal adenocarcinoma (PDAC).

# Data Sources

 Mouse scRNA-seq data were obtained from the Tuveson Lab (CSHL), available under GEO accession GSE315796

 Gene expression signature obtained from the following manuscript
 Dilly, J., Hoffman, M. T., Abbassi, L., Li, Z., Paradiso, F., Parent, B. D., Hennessey, C. J., Jordan, A. C., Morgado, M., Dasgupta, S., Uribe, G. A., Yang, A., Kapner, K. S., Hambitzer, F. P.,  Qiang, L., Feng, H., Geisberg, J., Wang, J., Evans, K. E., ... Aguirre, A. J. (2024). Mechanisms of resistance to oncogenic KRAS inhibition in pancreatic cancer. Cancer Discovery, 14(11), 2135–2157.  https://doi.org/10.1158/2159-8290.CD-24-0177
